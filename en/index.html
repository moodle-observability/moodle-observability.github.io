Open Source Moodle Observability

See what happens inside your Moodle

Open-source plugins and tools that bring observability to the Moodle LMS: error tracking, performance monitoring, logs, metrics and tracing, so administrators and developers find and fix problems faster.

Moodle Plugins

🔌 Moodle Plugins

Moodle plugins that send errors, performance data and other signals from the platform to observability services.

moodle-tool_sentry

Stable

Admin tool plugin that sends Moodle errors, exceptions and performance traces to Sentry (self-hosted or sentry.io). It can start before Moodle through auto_prepend_file, catching even database connection failures.

Error Tracking & APM Sentry
GitHub Marketplace Documentation

moodle-tool_prometheus

In development

OpenMetrics exporter: a token-protected /metrics endpoint with active users and sessions, adhoc task queue, quiz attempts in progress, MUC cache hit ratio and moodledata disk usage.

Metrics Prometheus OpenMetrics Grafana
GitHub Marketplace Documentation

moodle-tool_taskmonitor

In development

Detects a stopped cron, records scheduled task durations and failures, flags stuck or failing adhoc tasks and alerts administrators through Moodle messaging.

Cron & Tasks Alerts
GitHub Marketplace Documentation

moodle-tool_healthcheck

In development

A lightweight liveness endpoint and a readiness endpoint that checks the database, caches, moodledata and sessions, with a JSON report of each check.

Health Checks Kubernetes Load Balancer Probes
GitHub Marketplace Documentation

moodle-tool_otel

Research

OpenTelemetry tracing for Moodle: spans for requests, database queries, outgoing HTTP calls, web services and tasks, exported through OTLP to Jaeger, Tempo or Sentry.

Tracing OpenTelemetry OTLP
