Observabilidade Open Source para Moodle

Veja o que acontece dentro do seu Moodle

Plugins e ferramentas open source que trazem observabilidade ao Moodle: rastreamento de erros, monitoramento de desempenho, logs, métricas e tracing, para administradores e desenvolvedores encontrarem e corrigirem problemas mais rápido.

Plugins Moodle

🔌 Plugins Moodle

Plugins Moodle que enviam erros, dados de desempenho e outros sinais da plataforma para serviços de observabilidade.

🛰️

moodle-tool_sentry

Estável

Plugin de ferramenta administrativa que envia erros, exceções e traces de desempenho do Moodle para o Sentry (self-hosted ou sentry.io). Pode iniciar antes do Moodle via auto_prepend_file, capturando até falhas de conexão com o banco.

Rastreamento de Erros & APM Sentry
GitHub Diretório de Plugins Moodle
📊

moodle-tool_prometheus

Em desenvolvimento

Exportador OpenMetrics: endpoint /metrics protegido por token com usuários e sessões ativos, fila de adhoc tasks, tentativas de questionário em andamento, taxa de acerto do MUC e uso de disco do moodledata.

Métricas Prometheus OpenMetrics Grafana
GitHub Documentação
🩺

moodle-tool_taskmonitor

Em desenvolvimento

Detecta cron parado, registra duração e falhas das tarefas agendadas, aponta adhoc tasks presas ou falhando e avisa os administradores pelas mensagens do Moodle.

Cron & Tarefas Alertas
GitHub Documentação
✅

moodle-tool_healthcheck

Em desenvolvimento

Endpoint de liveness leve e endpoint de readiness que verifica banco de dados, caches, moodledata e sessões, com relatório JSON de cada verificação.

Health Checks Kubernetes Balanceador Probes
GitHub Documentação
🔭

moodle-tool_otel

Em pesquisa

Tracing com OpenTelemetry para o Moodle: spans de requisições, consultas ao banco, chamadas HTTP de saída, web services e tarefas, exportados via OTLP para Jaeger, Tempo ou Sentry.

Tracing OpenTelemetry OTLP
GitHub Documentação
